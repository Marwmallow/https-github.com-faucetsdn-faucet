# 🎬 Seamless Video Loop Maker

Автоматический скрипт для создания бесшовных зацикленных видео с различными вариантами перекрытия (crossfade).

## 🎯 Возможности

- ✅ **Множественные варианты** - создает несколько версий с разной длиной crossfade
- ✅ **Умный анализ** - автоматически находит оптимальную точку зацикливания
- ✅ **Простота использования** - один скрипт для всего процесса
- ✅ **Гибкость** - настраиваемые параметры перекрытия и количество повторений
- ✅ **Качество** - использует FFmpeg для профессиональной обработки

## 📋 Требования

### Установка FFmpeg

**Ubuntu/Debian:**
```bash
sudo apt update
sudo apt install ffmpeg
```

**macOS:**

**Windows:**
Скачайте с [ffmpeg.org](https://ffmpeg.org/download.html) и добавьте в PATH

**Проверка установки:**
```bash
ffmpeg -version
```

- Python 3.6+
- Стандартная библиотека (никаких дополнительных pip пакетов не требуется!)

## 🚀 Быстрый старт

### 1. Базовое использование

Создать варианты с перекрытиями от 0.5 до 3.0 секунд:

```bash
python video_loop_maker.py water_flow.mp4
```

Результат:
```
output/
├── variant_1_overlap_0.5s.mp4
├── variant_2_overlap_1.0s.mp4
├── variant_3_overlap_1.5s.mp4
├── variant_4_overlap_2.0s.mp4
├── variant_5_overlap_2.5s.mp4
└── variant_6_overlap_3.0s.mp4
```

### 2. Кастомные значения перекрытия

```bash
python video_loop_maker.py water_flow.mp4 -o 1.0 2.0 3.0
```

### 3. Автоматический поиск лучшего варианта (РЕКОМЕНДУЕТСЯ!)

```bash
python video_loop_maker.py water_flow.mp4 --analyze
```

Скрипт:
1. 🔍 Анализирует похожесть кадров начала и конца
2. 🎯 Находит оптимальную точку зацикливания
3. ✨ Создает лучший вариант + несколько близких альтернатив

### 4. Больше повторений цикла

```bash
python video_loop_maker.py water_flow.mp4 -l 10
```

Создаст 10 повторений цикла (для длинных видео).

### 5. Изменить папку вывода

```bash
python video_loop_maker.py water_flow.mp4 -d my_loops
```

## 📖 Полная документация параметров

```
usage: video_loop_maker.py [-h] [-o OVERLAPS [OVERLAPS ...]]
                           [-d OUTPUT_DIR] [-l LOOPS] [-a] input

positional arguments:
  input                 Входное видео файл

optional arguments:
  -h, --help            Показать справку
  -o, --overlaps        Длительности перекрытия в секундах
                        (по умолчанию: 0.5, 1.0, 1.5, 2.0, 2.5, 3.0)
  -d, --output-dir      Папка для выходных файлов (по умолчанию: output)
  -l, --loops           Количество повторений цикла (по умолчанию: 3)
  -a, --analyze         Анализировать похожесть кадров для поиска
                        оптимального перекрытия
```

## 🎨 Примеры использования

### Пример 1: Создание 8-часового видео водопада

```bash
# Шаг 1: Создать оптимальный цикл
python video_loop_maker.py waterfall_8sec.mp4 --analyze -l 50

# Результат: ~7 минут зацикленного видео

# Шаг 2 (опционально): Увеличить до 8 часов через повтор
# Можно снова прогнать через скрипт или использовать:
ffmpeg -stream_loop 60 -i output/optimized_overlap_X.Xs.mp4 \
       -c copy waterfall_8hours.mp4
```

### Пример 2: Batch обработка нескольких видео

```bash
#!/bin/bash
for video in *.mp4; do
    echo "Processing $video..."
    python video_loop_maker.py "$video" --analyze -d "loops_${video%.*}"
done
```

### Пример 3: Только короткие перекрытия для быстрого движения

```bash
# Для быстрых потоков воды используйте короткие crossfade
python video_loop_maker.py fast_water.mp4 -o 0.3 0.5 0.7 1.0
```

### Пример 4: Длинные перекрытия для медленного движения

```bash
# Для медленных облаков/дыма используйте длинные crossfade
python video_loop_maker.py clouds.mp4 -o 2.0 3.0 4.0 5.0
```

## 🎓 Как это работает

### Техническая схема

```
Исходное видео (8 секунд):
[████████████████████] 0s → 8s

Вариант с overlap 2s:
[████████████████████]        ← Базовый слой
            [████████████████████]  ← Наложенный слой (с начала)
            ↑
        Crossfade 2s

Результат (6s чистого цикла):
[██████▓▓▓▓▓▓████████▓▓▓▓▓▓] → повторить N раз
       ↑fade       ↑fade
```

### Алгоритм

1. **Разделение:** Видео дублируется на два слоя
2. **Смещение:** Второй слой накладывается со смещением (duration - overlap)
3. **Crossfade:** Применяется плавный переход opacity между слоями
4. **Цикл:** Результат повторяется N раз
5. **Варианты:** Процесс повторяется с разными значениями overlap

### Режим анализа (--analyze)

1. Извлекает первый кадр видео
2. Извлекает кадры на разных расстояниях от конца
3. Сравнивает их используя SSIM (Structural Similarity Index)
4. Выбирает offset с максимальной похожестью
5. Создает варианты вокруг оптимальной точки

## 💡 Советы для лучших результатов

### ✅ Что делать:

- **Стабилизируйте видео** - используйте штатив, gimbal или стабилизацию
- **Циклическое движение** - вода, огонь, облака работают лучше всего
- **Равномерная скорость** - постоянный темп движения
- **Используйте --analyze** - автоматический поиск почти всегда лучше
- **Тестируйте варианты** - проверьте все созданные файлы

### ❌ Чего избегать:

- **Handheld съемка** - тряска создает видимые скачки
- **Резкие изменения** - объекты входящие/выходящие из кадра
- **Линейное движение** - машина проезжающая через весь кадр
- **Слишком короткие клипы** - минимум 5-6 секунд рекомендуется
- **Изменение освещения** - fade in/out солнца создаст артефакты

## 🔧 Расширенные настройки

### Изменить качество выходного видео

Отредактируйте в скрипте:
```python
'-crf', '23',  # Меньше = лучше качество (18-28), больше размер файла
'-preset', 'medium',  # ultrafast, fast, medium, slow, veryslow
```

### Другие типы crossfade

FFmpeg поддерживает множество переходов. В скрипте замените:
```python
f"xfade=transition=fade:..."
```

На:
- `transition=fade` - классический fade (по умолчанию)
- `transition=wipeleft` - горизонтальная протирка
- `transition=circleopen` - круговое открытие
- `transition=dissolve` - растворение

Полный список: [FFmpeg xfade](https://trac.ffmpeg.org/wiki/Xfade)

### Добавить аудио зацикливание

Скрипт сохраняет аудио, но для бесшовного audio loop нужна дополнительная обработка:

```bash
# Извлечь и зациклить аудио отдельно с crossfade
ffmpeg -i input.mp4 -filter_complex \
  "[0:a][0:a]acrossfade=d=2:c1=tri:c2=tri" \
  -c:a aac output_audio.m4a
```

## 🐛 Решение проблем

### FFmpeg не найден
```
ffmpeg: command not found
```
**Решение:** Установите FFmpeg (см. раздел Требования)

### Перекрытие слишком длинное
```
❌ Error: Overlap 5.0s is too long for video duration 3.5s
```
**Решение:** Используйте меньшие значения overlap или более длинное видео

### Видимые швы в цикле
**Причины:**
- Нестабильное видео → стабилизируйте исходник
- Неоптимальное перекрытие → используйте `--analyze`
- Линейное движение → выберите другой клип
- Слишком короткий crossfade → увеличьте overlap

### Низкое качество выходного видео
**Решение:** Измените CRF в скрипте на меньшее значение (18-20 для высокого качества)
