# ⚡ Quick Start Guide

## 1️⃣ Установка FFmpeg

### Ubuntu/Debian:
```bash
sudo apt update && sudo apt install ffmpeg -y
```

### macOS:
```bash
brew install ffmpeg
```

### Windows:
Скачайте с [ffmpeg.org](https://ffmpeg.org/download.html)

---

## 2️⃣ Простейшее использование

### Автоматический режим (РЕКОМЕНДУЕТСЯ):
```bash
python3 video_loop_maker.py your_video.mp4 --analyze
```

Скрипт сам найдет лучшую точку зацикливания! ✨

### Результат:
```
output/
├── optimized_overlap_1.5s.mp4  ← Лучший вариант
├── variant_1_overlap_1.0s.mp4  ← Альтернатива
└── variant_2_overlap_2.0s.mp4  ← Альтернатива
```

---

## 3️⃣ Ручной режим

```bash
# Создать варианты с разными перекрытиями
python3 video_loop_maker.py your_video.mp4 -o 0.5 1.0 1.5 2.0 2.5 3.0
```

Получите 6 вариантов - выберите лучший визуально!

---

## 4️⃣ Batch обработка папки

```bash
# Обработать ВСЕ видео в папке
./batch_process.sh /path/to/videos/
```

---

## 5️⃣ Создать длинное видео

```bash
# 10 повторений цикла
python3 video_loop_maker.py your_video.mp4 --analyze -l 10

# Для 8-часового видео:
# 1. Создайте цикл с большим количеством повторений
python3 video_loop_maker.py water.mp4 --analyze -l 100

# 2. Или повторите результат через FFmpeg:
ffmpeg -stream_loop 50 -i output/optimized_overlap_X.Xs.mp4 \
       -c copy 8hour_video.mp4
```

---

## 📋 Шпаргалка по параметрам

| Параметр | Что делает | Пример |
|----------|-----------|---------|
| `--analyze` | Автоматический поиск лучшего перекрытия | `--analyze` |
| `-o` | Указать свои значения перекрытия (сек) | `-o 1.0 2.0 3.0` |
| `-l` | Количество повторений цикла | `-l 10` |
| `-d` | Папка для сохранения результатов | `-d my_loops` |

## 💡 Типичные сценарии

### Быстрый поток воды:
```bash

```

### Медленные облака:
```bash
python3 video_loop_maker.py clouds.mp4 -o 2.0 3.0 4.0 5.0
```

```bash
python3 video_loop_maker.py fire.mp4 --analyze
```

## ⚠️ Важно!

✅ **Видео ДОЛЖНО быть стабильным** (штатив, gimbal)
❌ **НЕ работает с handheld съемкой** (тряска создает швы)

## 🆘 Проблемы?

### FFmpeg не найден:
```bash
# Проверьте установку:
ffmpeg -version

# Если не работает - переустановите
```

### Видимые швы в цикле:
1. Используйте `--analyze` для автоматического поиска
2. Попробуйте другие значения перекрытия
3. Проверьте стабильность исходного видео

### Медленная обработка:
- Это нормально! FFmpeg обрабатывает видео качественно
- ~30-60 секунд на вариант для 10-сек видео
